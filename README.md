# 📋 Tickify – Smart To-Do List App Built with Flutter

A simple and interactive **To-Do List** application built using **Flutter**.  
This project helps beginners understand how to manage state, use lists, and build responsive UI with Flutter widgets.

---

## 🚀 Features

✅ Add new tasks dynamically  
✅ Display tasks in a scrollable list  
✅ Delete tasks with a single tap  
✅ Simple and responsive Material UI  
✅ Uses **setState()** for instant UI updates  

---

## 🧠 What You’ll Learn

- Building and structuring a Flutter app
- Managing state using `StatefulWidget`
- Using `TextEditingController` to capture user input
- Dynamically rendering lists with `ListView.builder()`
- Understanding widget hierarchy (Row, Column, Container, etc.)
